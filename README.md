# ManajemenInventoryTency

Visi Proyek (Project Context):
Sistem ini dibuat untuk menggantikan proses Stock Opname konvensional (menggunakan spreadsheet manual) di divisi Bar dan Floor sebuah kafe. Sistem harus menyelesaikan masalah kebingungan staf saat mengisi data, mengurangi human error, dan mengotomatiskan pemantauan stok barang habis pakai (seperti tisu, sendok plastik, susu, dll) maupun aset tetap.
